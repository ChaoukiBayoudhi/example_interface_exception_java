# Example interface exception Java

Exception, Interface, List, Map and Set in Java.

## Tech stack

- Java
- Lombok

## Concepts covered

Collections, console input (Scanner), custom exceptions, exception handling, interfaces.

## Project structure

- `Classes`: Mark, Student, StudentGroupList, StudentGroupMap, StudentGroupSet
- `Exceptions`: PredefinedExceptions, StudentException, StudentMarkException
- `Program`: Main
- `interfeaces`: IGroup

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run `Main` (it contains the `main` method).

The code uses Lombok annotations: add the Lombok library and enable annotation processing in your IDE.
